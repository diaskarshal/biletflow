# 007: Support chat — no file attachments

**Chosen:** Support messages are text-only for the academic MVP.

**Considered:** Letting attendees attach a screenshot (e.g. of a failed payment) to a support
message.

**Why:** File attachments mean object storage, upload validation, virus/type scanning
considerations, and UI for previewing attachments — a day of work for a feature the SRS itself
lists as optional ("Support-message file attachments" is explicitly a Bonus/Stretch feature,
info.pdf §8). Zero grade impact for the base MVP.

**Who decided:** Claude + user. **Date:** 2026-09-02.
